# QTracker

Десктопный клиент для работы с каталогом RuTracker.org со встроенным торрент-движком.

## Возможности

- **Каталог и поиск**: мгновенный поиск по раздачам, фильтрация по категориям (софт, игры, мультимедиа, ОС), сортировка по сидам, дате и размеру.
- **Предпросмотр раздач**: просмотр описаний, скриншотов и системных требований прямо в приложении.
- **Авторизация**: поддержка входа по логину/паролю, сессионной куке `bb_session` или через встроенное веб-окно (для решения капчи).
- **Встроенный торрент-движок**: автономный C++ qBittorrent, не требующий сторонней установки и настройки.
- **Сеть и обход блокировок**: поддержка зеркал RuTracker и работа через HTTP/SOCKS5 прокси.

## Требования

- Windows 10 / 11 (x64)

## Установка и запуск

### Готовые сборки
Скачайте актуальный релиз из раздела [Releases](https://github.com/edgemq/qtracker/releases):
- `QTracker-Portable-1.0.0.exe` — портативная версия без необходимости установки.
- `QTracker-Setup-1.0.0.exe` — стандартный установщик Windows.

### Сборка из исходников

```bash
# Клонирование репозитория
git clone https://github.com/edgemq/qtracker.git
cd qtracker

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка установочного пакета (.exe)
npm run dist
```
